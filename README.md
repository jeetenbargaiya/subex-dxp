# Subex DXP

New enterprise website platform for Subex.

## Technology Stack

- Next.js
- React
- TypeScript
- Payload CMS
- PostgreSQL
- Tailwind CSS

## Project Goals

- Build a modern enterprise website.
- Create a flexible content management system.
- Improve website performance and SEO.
- Implement enterprise-grade security.
- Reduce dependency on WordPress plugins.
